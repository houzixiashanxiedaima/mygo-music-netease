# 网易云音乐 · MyGo Music 插件

在 [MyGo Music](https://github.com/egoist/mygo-music) 中搜索和播放网易云音乐。需要 MyGo Music 0.1.20 或更新版本，无需额外服务。

网易云 CDN 封面使用 `{size}` 模板，由主程序按列表、卡片及播放页所需尺寸请求缩略图，减少首次下载和大图解码。0.1.20 之前的主程序不支持此模板，使用前请先升级。

## 安装和使用

1. 打开 MyGo Music → 设置 → 插件 → `+` → 从 GitHub 安装，填入 `sogud/mygo-music-netease`。也可从 [Releases](https://github.com/sogud/mygo-music-netease/releases) 下载 ZIP 后从本地安装，或选择本项目文件夹。从自己的 fork 安装时，把 `sogud` 换成 fork 的所有者名。
2. 确认插件页显示版本 `0.2.3`。来源不变时不要移除旧插件，按下面的「更新插件」操作。
3. 安装后，在来源选择器中选择 **网易云音乐**。
4. 点击 **登录**，用网易云音乐手机 App 扫码，访问自己的歌单和喜欢的音乐。
5. 每日推荐、私人雷达、个性化歌单和播客发现集中在 **发现音乐**；侧栏保留 **私人漫游** 专页和 **排行榜**。推荐歌单加载失败时，可在该区域点 **查看全部** 重试，其他入口仍可使用。

## 更新插件

本 Fork 的新增功能需要从本仓库安装；上游原版独立发布。已从本仓库安装时，用菜单更新即可，不需要移除插件。

1. 打开 MyGo Music → 设置 → 插件。
2. 在插件菜单选择 **Check for Updates**。
3. 发现新版本后点 **Update**。

更新源的读取顺序：

- 仓库有 Release 时，优先使用最新 Release。
- 仓库没有 Release 时，回退到默认分支 `main` 的最新提交。

更新会热替换插件文件，不需要重启 MyGo Music。

只有来源不同、插件 ID 相同（`netease`）时，才需要先移除旧插件，再从新来源安装。

## 功能

- 歌曲、专辑、歌手、歌单和播客搜索，支持翻页；输入时给出歌曲、歌手、专辑和歌单候选。
- 推荐歌单、排行榜、歌单详情，专辑和歌手详情。
- 发现页的「推荐播客」和「热门播客」入口；热门播客可用「上一页」「下一页」浏览。
- 登录后的每日推荐、私人雷达、个性化歌单，以及持续补充歌曲的私人漫游、熟悉的歌和新发现。
- 侧栏「最近播放」：本机保留每个账号最近 100 首歌曲，并与网易云已有的播放记录合并。
- 网易云 App 扫码登录、会话恢复、个人歌单、喜欢列表、喜欢/取消喜欢。
- 将歌曲添加到自建歌单或从中移出；已存在的歌曲不会重复加入，混合批次只补充缺失歌曲。
- 标准、高音质和无损音质。
- LRC 歌词和翻译，交给 MyGo Music 原生播放界面显示。
- 歌曲和播客节目的只读评论，支持分页。
- 登录后从「我的播客」读取网易云已订阅播客，浏览、分页播放节目；不修改订阅。

## 最近播放

侧栏的「最近播放」和发现页「继续收听 → 最近播放」打开同一列表，合并两个来源，按本地新播放在前、云端记录在后的顺序去重，最多显示 100 首：

- 本机记录：从本版本开始，宿主每次真正开始播放歌曲时回调插件，插件只记歌曲 ID 和时间，不请求接口。预取及取源失败不会记录；旧版本的本机播放历史无法可靠回补。
- 云端记录：登录后读取网易云已有的播放记录，一次请求最多 100 条；不写入、不上传听歌记录。
- 本机记录按账号分开保存；退出登录或切换账号后不会混入其他账号的历史。播客节目不进入歌曲历史。
- 打开页面时，两批记录合并为一次歌曲详情请求，同时补齐云端记录缺少的播放权限字段。某首歌已被删除时，本机记录中的条目直接略过。
- 云端记录加载失败时只显示本机记录，并在页面上说明；登录失效仍会提示重新登录。

## 播放失败与音质降档

插件按设置请求音质。某一档没有可播放音源时，向下再试一档：无损 → 高音质 → 标准音质。每档在临时失败时最多重试一次，不会无限重试。

- 只在“这一档确实没有音源”时降档。确认的形态有两种：返回 `code: 200` 但没有音频地址，以及返回 `code: 404`。
- 返回试听片段时直接报错：不降档，也不把试听当完整歌曲播放。
- 临时失败在同一音质重试，不降档：拒绝码 `460`，顶层结果码 `429` 和 `5xx`，超时，网络错误，HTTP 失败（`429`/`5xx`），以及音源记录内的 `429`/`5xx`。
- 账号无权播放或登录失效时立即报错，不换档重试。
- 未识别的结果码，或“有地址却也报非 200”这类自相矛盾的返回，不算“这一档没有音源”：停在当前档位，保留结果码，不降档。音源记录里的 `301` 和 `302` 同样按这一条处理。

### 取源冷却、短缓存与总时限

- 临时失败后，后续取源共享约 2 秒冷却；冷却期间若又收到拒绝，会延长等待。实际取源请求依次放行，至少间隔 200 毫秒，避免等待者同时发出请求；搜索、歌单等非取源接口不受影响。
- 成功的取源结果最多复用 15 秒，最多保留 12 条。复用键包含会话、歌曲和本次请求的音质；回报的仍是服务端证明的实际音质，不把降档结果标成请求档位。切换账号或退出登录会清空复用结果。
- 一次取源从开始等待到结束最多使用 25 秒，给主程序的 30 秒超时留出余量。等待、重试和账号检查都计入这个时限。
- 服务端返回合法的 `Retry-After` 时，至少等待它指定的时间。这个时间超过本次预算时直接停止，不提前重试换取成功。
- 本实现未确认网易云音源响应中过期字段的单位，不据此推断有效期；只缓存完整、非试听的音源，并使用上面的短时限。

主程序对最终失败的歌曲会跳到下一首，插件无法阻止这一步。插件能做的是减少误跳（不再因为缺少某一档音源而失败），并记录每次失败的原因。

## 登录失效与 401

网易云用状态码 `401` 回答两类请求：当前账号无权访问该内容，以及登录已失效。只看状态码无法区分。

插件先保留会话，再用只读请求 `/api/nuser/account/get` 查当前账号。30 秒内的多次 401 共用一次检查；窗口过后再遇到 401 会重新检查，不会一直复用第一次的结果。共享检查自身最多等待 10 秒。某一次取源先用完时间预算时，只停止这个调用等待，不会取消其他调用仍在等待的检查。检查失败不写入窗口，下一次 401 会重新询问。

顶层的 `401` 和音源记录里的 `401` 走同一套判断。

| 检查结果 | 插件行为 |
| --- | --- |
| 返回账号 | 报“当前账号无权访问该内容”或“当前账号无权播放这首歌”，保留会话，主程序跳到下一首 |
| 不返回账号 | 确认为登录失效：清除会话，提示重新登录 |
| 请求失败（网络、超时、`460`），或返回了无法使用的账号信息 | 视为仍有会话：报无权访问，不清除会话，也不缓存这个结果 |

检查请求本身不改登录状态。没有可用账号 ID 的账号响应既不是“已登录”，也不是“登录失效”：插件如实报错，不清会话。

顶层的 `301` 和 `302` 不检查，直接提示重新登录。音源记录里的 `301`/`302` 没有这层含义证据：插件不清会话，也不降档，只报错并保留结果码。

## 排查播放问题

主程序不写日志，插件的 `console` 输出也没有可查看的位置。插件把最近 20 条取源诊断（含成功复用记录）写进自己的存储：`~/Library/Application Support/MyGo Music/plugin-data/netease/storage.json` 的 `streamLog` 键。

```sh
jq '.streamLog[-3:]' ~/Library/Application\ Support/MyGo\ Music/plugin-data/netease/storage.json
```

每条记录包含：时间 `at`、歌曲 ID `song`、本次请求档位 `level`、结果码 `code`、是否有地址 `hasURL`、是否试听 `trial`、服务端返回的档位 `actual`、结果 `outcome`。另记录本次调用累计尝试序号 `attempt`、累计等待毫秒数 `waitMs` 和累计耗时毫秒数 `elapsedMs`；短缓存命中时这三项均为 0。

| `outcome` | 含义 |
| --- | --- |
| `ok` | 取得可播放音源 |
| `cached` | 短缓存命中，没有再次请求 |
| `missing` | 这一档没有音源，已降档 |
| `trial` | 只有试听权限 |
| `denied` | 账号无权播放 |
| `empty` | 返回成功，但没有这首歌的音源 |
| `transient` | 请求被拒绝、超时或服务端错误 |
| `refused` | 返回了未识别的结果码，已停止降档 |
| `error` | 响应不可用，例如地址或格式不受支持 |

`code` 会记录能拿到的数值：接口的顶层结果码（如 `460`、`405`）、HTTP 失败状态码（如 `503`），以及音源记录内的结果码。没有数值时记为 `null`。顶层 `429` 和 `5xx` 结果码按临时失败处理：在同一音质重试一次，不降档。其他未识别结果码只报一次错误。

记录只保留最后 20 条，不会无限增长；不包含音频地址、Cookie、请求头或账号信息。

### 缓存与音质标签

主程序按插件回报的档位给缓存文件命名，查询缓存时接受“同档或更高档”。所以插件回报的档位必须真实：无损音质报 `lossless`；返回 FLAC 但档位名不认识时也报 `lossless`；已知有损格式（`mp3`、`ogg`）即使档位名是 `lossless` 或 `hires` 也只报 `high`；其他格式最多报 `high`。

如果设置为无损、而某首歌只有高音质，超过插件的 15 秒短复用窗口后，再次播放仍会重新取源。这是主程序的缓存规则（只接受同档或更高档），插件不会把高音质文件标成无损来复用。

## 私人漫游没有歌曲时

私人漫游、熟悉的歌和新发现依赖网易云的个性化服务。关闭该服务时，账号即使已经登录，电台接口也可能返回成功状态和空歌曲列表。

请在网易云官方 App 的 **设置 → 消息和隐私 → 个性化服务** 中确认该开关已开启，然后回到 MyGo Music 点击 **开始收听**。该隐私设置由你在官方 App 中管理。若已开启但仍没有歌曲，请稍后重试。

电台卡片会显示这项前置条件。返回空列表时，插件会查询个性化服务设置；确认已关闭时，返回带有恢复说明的错误。重新开始收听会重新请求歌曲。
