# 网易云音乐 · MyGo Music 插件

在 [MyGo Music](https://github.com/egoist/mygo-music) 中搜索和播放网易云音乐。需要 MyGo Music 0.1.20 或更新版本，无需额外服务。

网易云 CDN 封面使用 `{size}` 模板，由主程序按列表、卡片及播放页所需尺寸请求缩略图，减少首次下载和大图解码。0.1.20 之前的主程序不支持此模板，使用前请先升级。

## 安装和使用

1. 打开 MyGo Music → 设置 → 插件 → `+` → 从 GitHub 安装，填入 `sogud/mygo-music-netease`。也可从 [Releases](https://github.com/sogud/mygo-music-netease/releases) 下载 ZIP 后从本地安装，或选择本项目文件夹。从自己的 fork 安装时，把 `sogud` 换成 fork 的所有者名。
2. 确认插件页显示版本 `0.1.8`。已在用旧版本时，先移除旧插件，再按上一步重新安装，然后重启 MyGo Music。
3. 安装后，在来源选择器中选择 **网易云音乐**。
4. 点击 **登录**，用网易云音乐手机 App 扫码，访问自己的歌单和喜欢的音乐。
5. 每日推荐、私人雷达和个性化歌单集中在 **发现音乐**；侧栏保留 **私人漫游** 专页和 **排行榜**。推荐歌单加载失败时，可在该区域点 **查看全部** 重试，其他入口仍可使用。

## 功能

- 歌曲、专辑、歌手、歌单和播客搜索，支持翻页。
- 推荐歌单、排行榜、歌单详情，专辑和歌手详情。
- 登录后的每日推荐、私人雷达、个性化歌单，以及持续补充歌曲的私人漫游、熟悉的歌和新发现。
- 网易云 App 扫码登录、会话恢复、个人歌单、喜欢列表、喜欢/取消喜欢。
- 将歌曲添加到自建歌单或从中移出；已存在的歌曲不会重复加入，混合批次只补充缺失歌曲。
- 标准、高音质和无损音质。
- LRC 歌词和翻译，交给 MyGo Music 原生播放界面显示。
- 歌曲和播客节目的只读评论，支持分页。
- 登录后从「我的播客」读取网易云已订阅播客，浏览、分页播放节目；不修改订阅。

## 播放失败与音质降档

插件按设置请求音质。某一档没有可播放音源时，向下再试一档：无损 → 高音质 → 标准音质。每档在临时失败时最多重试一次，不会无限重试。

- 只在“这一档确实没有音源”时降档。
- 返回试听片段时直接报错：不降档，也不把试听当完整歌曲播放。
- 接口拒绝（460）、超时、网络错误和服务端 5xx 属于临时失败：同一音质重试，不降档。
- 账号无权播放或登录失效时立即报错，不换档重试。

主程序对最终失败的歌曲会跳到下一首，插件无法阻止这一步。插件能做的是减少误跳（不再因为缺少某一档音源而失败），并记录每次失败的原因。

## 登录失效与 401

网易云用状态码 `401` 回答两类请求：当前账号无权访问该内容，以及登录已失效。只看状态码无法区分。

插件先保留会话，再用只读请求 `/api/nuser/account/get` 查当前账号，30 秒内的多次 401 共用一次检查。

| 检查结果 | 插件行为 |
| --- | --- |
| 返回账号 | 报“当前账号无权访问该内容”，保留会话，主程序跳到下一首 |
| 不返回账号 | 确认为登录失效：清除会话，提示重新登录 |
| 请求失败（网络、超时、`460`） | 视为仍有会话：报无权访问，不清除会话 |

检查请求本身不改登录状态。状态码 `301` 和 `302` 不检查，直接提示重新登录。

## 排查播放问题

主程序不写日志，插件的 `console` 输出也没有可查看的位置。插件把最近 20 次取音源尝试写进自己的存储：`~/Library/Application Support/MyGo Music/plugin-data/netease/storage.json` 的 `streamLog` 键。

```sh
jq '.streamLog[-3:]' ~/Library/Application\ Support/MyGo\ Music/plugin-data/netease/storage.json
```

每条记录包含：时间 `at`、歌曲 ID `song`、本次请求档位 `level`、结果码 `code`、是否有地址 `hasURL`、是否试听 `trial`、服务端返回的档位 `actual`、结果 `outcome`。

| `outcome` | 含义 |
| --- | --- |
| `ok` | 取得可播放音源 |
| `missing` | 这一档没有音源，已降档 |
| `trial` | 只有试听权限 |
| `denied` | 账号无权播放 |
| `empty` | 返回成功，但没有这首歌的音源 |
| `transient` | 请求被拒绝、超时或服务端错误 |
| `error` | 响应不可用，例如地址或格式不受支持 |

记录只保留最后 20 条，不会无限增长；不包含音频地址、Cookie、请求头或账号信息。

### 缓存与音质标签

主程序按插件回报的档位给缓存文件命名，查询缓存时接受“同档或更高档”。所以插件回报的档位必须真实：无损音质报 `lossless`；返回 FLAC 但档位名不认识时也报 `lossless`；其他格式最多报 `high`。

如果设置为无损、而某首歌只有高音质，每次播放都会重新取一次音源。这是主程序的缓存规则（只接受同档或更高档），插件不会把高音质文件标成无损来复用。

## 私人漫游没有歌曲时

私人漫游、熟悉的歌和新发现依赖网易云的个性化服务。关闭该服务时，账号即使已经登录，电台接口也可能返回成功状态和空歌曲列表。

请在网易云官方 App 的 **设置 → 消息和隐私 → 个性化服务** 中确认该开关已开启，然后回到 MyGo Music 点击 **开始收听**。该隐私设置由你在官方 App 中管理。若已开启但仍没有歌曲，请稍后重试。

电台卡片会显示这项前置条件。返回空列表时，插件会查询个性化服务设置；确认已关闭时，返回带有恢复说明的错误。重新开始收听会重新请求歌曲。

## 开发

运行不需要构建或依赖安装；Node 和 Python 仅用于本地检查及打包：

```sh
npm run check
npm test
npm run pack
```
